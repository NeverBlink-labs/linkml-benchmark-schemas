ONE Record Code Lists Ontology, by IATA. Version 1.1.0, ontology IRI `https://onerecord.iata.org/ns/code-lists`. https://www.iata.org/one-record/

Downloaded on 2026-10-20 from https://raw.githubusercontent.com/IATA-Cargo/ONE-Record/2445a2b05087bf0bbdfba3bf76b9a8702edefd76/working_draft/ontology/IATA-1R-CL-Ontology.ttl

This is imported by the ONE Record data model, which is in the `iata-one-record` folder. It covers the code lists used in the standard: cXML code lists, IATA Resolutions, CITES and UN recommended codes. It is mostly named individuals – over 1,200 of them.
