# LinkML benchmark datasets

Directory structure:

- `benchmark_data/` – a collection of LinkML schemas for benchmarking and research purposes. Some schemas were modified to make them valid. Please see the individual READMEs for sources, licensing information and our changes.
- `results/` – benchmark results for the schemas in `benchmark_data/`.
- `analysis/` – analysis code and figures for the LinkML-Scala paper.
- [Benchmark code](https://github.com/NeverBlink-OSS/linkml-scala/tree/dbd4d1eccfad3952c8e8887ebae5a527fed2cb79/benchmark/src)
