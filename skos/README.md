# SKOS vocabularies

A collection of real-world SKOS vocabularies (thesauri, taxonomies, code lists) under open licenses that allow commercial use and derivatives. The files are taken as published and converted to gzip-compressed N-Triples, without other changes to their content. Each folder holds one data file, `main.nt.gz`. See the README in each folder for the source, license and download details.
